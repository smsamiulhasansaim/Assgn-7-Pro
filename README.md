1. What is JSX and why is it used?
JSX is a way to write HTML-like code inside JavaScript. It makes building UI easier and code more readable.

2. Difference between State and Props
State is a component’s own data that can change, while Props are data passed from parent to child and cannot be changed by the child.

3. What is the useState hook and how does it work?
useState is a React hook that lets functional components have state, and updating it re-renders the component.

4. How can state be shared between components?
State is usually kept in a common parent and passed down to child components through props.

5. How is event handling done in React?
Event handlers are functions triggered by user actions, using camelCase syntax like onClick, onChange, etc.
